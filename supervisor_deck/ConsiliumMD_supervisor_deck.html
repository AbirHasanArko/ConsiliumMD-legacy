When guidelines disagree,

the right answer is rarely "retrieve more."

A decision-theoretic clinical AI that separates epistemic from normative conflict
and routes each conflict to the action that actually reduces decision error.

The problem with today's clinical LLMs

Guideline conflicts are everywhere — current systems handle them by guessing.

What clinicians actually see
  • Two guidelines disagree.
    • BP target: ACC/AHA <130/80, ESC <140/90.
    • Opioid MME: CDC ≤50, some societies allow higher.
  • The LLM retrieves more evidence, then picks one.
    • It cannot tell whether the disagreement is about evidence or values.
  • Worst case: it silently picks the higher-authority source.
Why "retrieve more" is the wrong reflex
  • For epistemic conflicts: more retrieval can resolve them.
  • For normative conflicts (shared evidence, different value weights): more retrieval cannot resolve them.
  • Yet today's systems apply one uniform policy: retrieve, retrieve, retrieve.
  • → wasted compute, delayed answers, and wrong-action routings.

The core insight

Not all conflicts are the same kind of problem.

Epistemic conflict

Beliefs differ · values align

Right action: retrieve or escalate

Normative conflict

Beliefs align · values differ

Right action: elicit preference

Wrong action on the normative side: retrieve more. Right action: do less.

What CARMA is — and isn't

“A clinical-reasoning system that types each guideline conflict as epistemic or normative before deciding what to do about it.”
What it is NOT What it IS
Not a new foundational LLM (uses GPT-4/Claude via API). An agentic routing architecture built around a specialized classifier.
Not just "better RAG." A decision-theoretic framework evaluating Expected Value of Sample Information (EVSI).
Not trying to "solve" ethics. A system that detects when an ethical/value trade-off is required and defers to humans.

What’s genuinely novel about CARMA

Four claims the paper stakes out — each testable, each falsifiable.

★

Revealed-Preference Decomposition (RPD)

Each guideline is modeled as solving a personal utility problem over a shared belief. Where sources cite overlapping evidence, RPD inverts their numeric thresholds to recover their implicit harm-vs-benefit weights.

★

A provable identifiability boundary

RPD is not a heuristic: Claim 1 and 2 are formal. If sources cite disjoint evidence on non-comparable metrics, the decomposition is observationally equivalent and cannot be recovered.

★

Gated routing on conflict type

CARMA runs EVPI/EVSI on the epistemic branch and a preference-elicitation step on the normative branch.

★

A type-labeled benchmark (CECB-T)

Rather than scaling up an existing benchmark, CARMA contributes a small, clinician-validated benchmark that labels each case as epistemic, normative, or mixed.

Why this is different from prior work

CARMA names a blind spot in a high-profile, active research thread.

Existing system How it handles a conflict Where CARMA differs
MDAgents Routes by task complexity. Multi-agent collaboration for “hard” cases. Complexity ≠ conflict type. A normative conflict can be “easy” but unresolvable by retrieval.
VoI-gated agents Apply one expected-value policy to every ambiguity. Assume more info = better. That assumption fails on normative conflicts — more retrieval has zero expected value when evidence is already complete.
Self-correction Trust the model’s stated confidence; iterate to “fix” wrong answers. LLMs cannot self-correct without external feedback. CARMA replaces self-report with a formal estimator.

The paper’s central claim

Baseline B3 (uniform EVPI on every conflict) is measurably worse than CARMA on the normative subset — while performing comparably on the epistemic subset. That gap is the contribution.

H1

RPD correctly classifies conflict type for ≥80% of identifiable-regime cases.
H2

Uniform EVPI (B3) is measurably worse than the full system on the normative subset.
H3

The preference-elicitation branch produces higher clinician-rated appropriateness.
H4

Gated routing produces ≥15% fewer wrong-action routings than any baseline.

How we evaluate it

Four baselines, four ablations, seven metrics, type-labeled benchmark.

Baselines (4)
  • B1 LLM self-reported.
  • B2 Evidence-concordance.
  • B3 Uniform EVPI on every conflict.
  • B4 MDAgents complexity.
Ablations (4)
  • A1 Remove classifier.
  • A2 Remove preference elicitation.
  • A3 EVSI vs. blind top-k.
  • A4 Heuristic vs. RPD.
Metrics (7)
  • Routing accuracy
  • Wasted-retrieval rate
  • Clinician appropriateness
  • Cost & latency

Takeaways

  1. CARMA names a real blind spot. VoI-based / "retrieve more" policies fail on normative conflicts.
  2. It contributes something the field does not have. A small, clinician-validated, type-labeled benchmark (CECB-T).
  3. It is a testable, falsifiable claim. H2 (uniform EVPI loses on the normative subset) is the result the paper is built to deliver.
  4. ConsiliumMD already exists as a working product surface. CARMA plugs in as a reasoning provider behind a clean adapter.
  5. What we need now. Sign-off to run the formal RPD evaluation on CECB-T.
