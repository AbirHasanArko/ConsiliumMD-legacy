The problem with today’s clinical LLMs

Guideline conflicts are everywhere — current systems handle them by guessing.

What clinicians actually see
  • Two guidelines disagree.
  • BP target: ACC/AHA <130/80, ESC <140/90.
  • Opioid MME: CDC ≤50, some societies allow higher with risk–benefit discussion.
  • The LLM retrieves more evidence, then picks one and writes it as a recommendation.
  • It cannot tell you whether the disagreement is about the evidence or about the values being traded off.
  • Worst case: it silently picks the higher-authority source and calls it “guideline-concordant.”
Why “retrieve more” is the wrong reflex
  • For epistemic conflicts (same evidence, different reading): more retrieval can resolve them if a published net-benefit model exists.
  • For normative conflicts (shared evidence, different value weights): more retrieval cannot resolve them — the evidence is already complete.
  • Yet today’s systems apply one uniform policy: retrieve, retrieve, retrieve.
  • → wasted compute, delayed answers, and wrong-action routings on the normative subset.

The core insight

Not all conflicts are the same kind of problem.

What CARMA is — and isn’t

Read-only reference at D:\Documents\HelloMed_X_CARMA\CARMA

“A clinical-reasoning system that types each guideline conflict as epistemic or normative before deciding what to do about it.”
What CARMA does
  • Takes a clinical case + decision class (e.g. BP target, statin, anticoagulation in AF) + retrieved guideline sources.
  • Estimates each source’s beliefs and utility weights from the cited evidence — not from self-reported confidence.
  • Returns a RoutingDecision ∈ {answer, retrieve, elicit, escalate} with a transparent, auditable trail.
What CARMA does not do
  • It is not a chatbot and not a generic RAG wrapper.
  • It does not treat every conflict the same way — uniform “retrieve more” is the baseline it is designed to beat.
  • It does not silently pick a higher-authority guideline. Normative conflicts are surfaced, not resolved by authority.

What’s genuinely novel about CARMA

Four claims the paper stakes out — each testable, each falsifiable.

★

Revealed-Preference Decomposition (RPD)

Each guideline is modeled as solving a personal utility problem over a shared belief. Where sources cite overlapping evidence, RPD inverts their numeric thresholds to recover their implicit harm-vs-benefit weights. This separates the two kinds of conflict from observables alone.

★

A provable identifiability boundary

RPD is not a heuristic: Claim 1 (identifiable regime) and Claim 2 (impossibility result) are formal. If sources cite disjoint evidence on non-comparable metrics, the decomposition is observationally equivalent and cannot be recovered — a stated limit, not an engineering gap.

★

Gated routing on conflict type

CARMA runs EVPI/EVSI on the epistemic branch and a preference-elicitation step on the normative branch. Uniform EVPI on all conflicts (Baseline B3) is the comparison the paper is built to lose to — specifically on the normative subset.

★

A type-labeled benchmark (CECB-T)

Rather than scaling up an existing benchmark, CARMA contributes a small (150–250 case), clinician-validated benchmark that labels each case as epistemic, normative, or mixed/non-identifiable. Cohen’s κ on type labels is reported.

Why this is different from prior work

CARMA names a blind spot in a high-profile, active research thread.

Existing system How it handles a conflict Where CARMA differs
MDAgents
NeurIPS 2024		 Routes by task complexity. Multi-agent collaboration for “hard” cases. Complexity ≠ conflict type. A normative conflict can be “easy” to phrase but unresolvable by retrieval.
Generic RAG + heuristics Concatenates, ranks, or picks top-k. Resolution = which chunk wins. Heuristics are surface-level. CARMA classifies the structure of the disagreement.
VoI-gated LLM agents
e.g. SAGE-Agent		 Apply one expected-value policy to every ambiguity. Assume more info is always better. That assumption fails on normative conflicts — more retrieval has zero expected value when evidence is already complete. CARMA’s contribution is precisely this distinction.
Self-confidence / self-correction
Huang et al., ICLR 2024		 Trust the model’s stated confidence; iterate to “fix” wrong answers. LLMs cannot self-correct without external feedback. CARMA replaces self-report with a formal estimator over the cited evidence.
Higher-authority tie-breaking When sources disagree, pick the more prestigious body. Silently authoritative. CARMA refuses — normative conflicts are surfaced to the clinician and the patient.

System architecture

From clinical case to routed action — with an audit trail at every step.

Where ConsiliumMD wraps CARMA
  • ConsiliumMD owns auth, RBAC, patient/case data, and the human-in-the-loop review queue.
  • CARMA is invoked as a reasoning provider behind a clean adapter (RoutingDecision, ConflictContingentExplanation, SafetyAuditResult).
  • Every routing → ReasoningSnapshot · every action → ActionLog · every event → append-only AuditEvent.
  • Out-of-MVP-scope classes (opioid_threshold, eol_care_intensity) blocked at the API with HTTP 409 — no unvalidated coverage.

Data model — the audit trail is the product

Every routing is replayable, every action attributable.

Invariants the schema enforces
  • Recommendation state machine: pending → answered / retrieved / elicit_pending / escalated / closed.
  • Model version pinning: every snapshot records the model_version_id — old cases stay interpretable when models change.
  • Evidence lives under snapshots — citations cannot float free.
  • AuditEvent is append-only: DB trigger raises on any UPDATE or DELETE.
  • DecisionClassScope is the single gate: unknown or out-of-scope classes fail with HTTP 409.

The paper’s central claim

The result it has to deliver.

THE RESULT THE PAPER HAS TO DELIVER

Baseline B3 (uniform EVPI on every conflict) is measurably worse than CARMA on the normative subset — while performing comparably on the epistemic subset. That gap is the contribution.

H1
RPD correctly classifies conflict type for ≥80% of identifiable-regime cases and correctly flags ≥70% of non-identifiable cases as such.
H2
Uniform EVPI (B3) is measurably worse than the full system on the normative subset — wasted retrieval, delayed answers, wrong-tradeoff recommendations — while comparable on the epistemic subset.
H3
The preference-elicitation branch produces higher clinician-rated appropriateness on normative conflicts than retrieval-based resolution.
H4
Gated routing produces ≥15% fewer wrong-action routings than any single-policy baseline.

How we evaluate it

Four baselines, four ablations, seven metrics, type-labeled benchmark.

Baselines (4)
  • B1 LLM self-reported confidence.
  • B2 Evidence-concordance-only / old ECL.
  • B3 Uniform EVPI on every conflict (the key comparison).
  • B4 MDAgents complexity routing.
Ablations (4)
  • A1 Remove classifier (collapses to B3).
  • A2 Remove preference elicitation (normative → retrieval).
  • A3 EVSI vs. blind top-k retrieval.
  • A4 Heuristic vs. RPD classifier.
Metrics (7)
  • Routing accuracy
  • Wasted-retrieval rate
  • EVPI/EVSI calibration
  • Clinician-rated appropriateness (Likert 1–7)
  • Cost (LLM calls + latency / path)
  • RPD recovery accuracy (synthetic)
  • RPD–clinician agreement (Cohen’s κ)

Takeaways

What we want the supervisor to walk away with.

  1. CARMA names a real blind spot. VoI-based / “retrieve more” policies fail on normative conflicts. The paper formalizes the distinction and proves an identifiability boundary.
  2. It contributes something the field does not have. A small, clinician-validated, type-labeled benchmark (CECB-T). The contribution is the decision-theoretic design, not dataset size.
  3. It is a testable, falsifiable claim. H2 (uniform EVPI loses on the normative subset) is the result the paper is built to deliver. Four baselines × four ablations × seven metrics, paired bootstrap.
  4. ConsiliumMD already exists as a working product surface. Auth, RBAC, decision-class scope, audit trail, reviewer queue, model-versioning — all wired. CARMA plugs in as a reasoning provider behind a clean adapter.
  5. What we need now. Sign-off to run the formal RPD evaluation on CECB-T against B1–B4, and clinical collaborators for the type-label validation pass.
